# Лабораторна робота №7: Багатопотокова обробка відео з OpenCV

## Опис проекту
Програма реалізує обробку відеопотоку в реальному часі з використанням бібліотеки OpenCV. Основна особливість цієї роботи — перенесення важких обчислень (нейромережевої детекції облич) у фоновий потік для збереження високого FPS основного інтерфейсу.

## Функціонал
- **Фільтри обробки:** Інверсія, розмиття за Гаусом, детектор меж Кенні, ефект Glitch (зсув каналів).
- **Face Detection:** Використання претренованої моделі ResNet-SSD (Caffe) для пошуку облич. 
- **Multithreading:** - Головний потік: Захоплення відео, накладання легких фільтрів та відмальовка UI.
  - Фоновий потік (`std::thread`): Асинхронний інференс нейромережі.
  - Синхронізація: Використання `std::mutex` та `std::lock_guard` для безпечного доступу до спільних кадрів.
